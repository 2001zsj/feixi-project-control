# CloudBase 首批发布：同步保护

发布标记：`2026-09-26-sync-protection-1`。

修复普通写入失败后显示“已同步”、远程刷新覆盖失败修改，以及刷新请求进行中本地编辑被覆盖的问题。失败修改保存在独立 outbox，失败状态持续可见，可点“重试同步”；重开页面时按原 revision 验证恢复，远端已变更则保留修改并报告冲突。冲突下读取云端前保留本机备份。恢复过期 outbox 不用新 revision 强行覆盖云端。

正常启动不再执行旧业务迁移，也不用 SEED 业务事实填充缓存；旧/损坏缓存备份后从 CloudBase 读取。云端连接前页面编辑控件暂不可用，读取成功后恢复；导出与导航保留。实际共享数据、undo/redo、远程命令回执及历史项目格式未迁移。

本次包含原分支尚未上线的 15 秒刷新及立即刷新按钮。不包括 V1.0 状态/动作层重构和 UI 减法；这些仍按设计分批执行。
